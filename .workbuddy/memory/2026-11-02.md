## ZFPZ001088 真实凭证联调（2026-11-03 下午）
- 参数：区划500000 / 年度2026 / vtCode=5214（国库集中支付凭证）/ 编号ZFPZ001088
- readVoucherByNo 成功：MOF 9332 字符 base64（VoucherFlag=1），内层 Voucher XML 4766 字（金额1.91、南昌市局本级、收款人"测试-支付"）
- **stamp 参数真实格式已确认**：`<?xml version="1.0" encoding="GBK"?><Stamps><Stamp VoucherNo="..." No="签章位置" SN="印章序列号"/></Stamps>`（根节点 Stamps，位置属性名是 No）
- 服务端校验链：根节点/字段错→EVS708 签章列表为空；属性名错→EVS707 签章位置不存在[null]；正确且已盖章→EVS507 已盖章；未盖章→EVS502/ESS506（印章服务无该位置印章原文）
- queryVoucherSignStampPositions 返回 {位置: guid}，该单已盖章 qz_01/qz_02/qz_05；qz_03/qz_04/cz_blz 未盖章
- getSnInfo 需 凭证号个数==位置个数 成对传；返回 base64 `<Certs><Cert VoucherNo StampNo><SN><DN>`
- 生成器待改：link-options 的 stamp 分支仍输出 SignStampList（错误格式），应改为 Stamps + 按位置查 getSnInfo 取 SN
