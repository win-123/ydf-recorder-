## ydf-browser 0.1.42 兼容性评估（recorder v0.1.2）

- 结论：recorder 产出的 DSL 与 ydf-browser 0.1.42 兼容，无破坏性变更，不需要紧急更新。
- 全部 18 组件 / ~25 operation 在新版 36 项白名单内（table.click_cell_link、amount_unit.set 均正确）；popup_reference target 键（title/match/value）符合严格白名单；登录链路与 9 个端点默认值与新版一致。
- 待改进（按优先级）：
  1. workflow_panel.click（0.1.42 新增）未识别，工作流面板操作会被 fallback 误分类
  2. auth.py 无 SMS 二次验证支持（ydf-browser 有 getValiImage/sendTfaCode/tfaLogin）
  3. replay.py 不校验内嵌运行时版本（.ydf-browser-runtime 可能是旧版）

- 关键事实：DSL 无版本号机制，真正的契约是 ydf_browser/dsl.py 的 COMPONENT_TARGET_SCHEMAS 白名单；registry.py 注释锚定 0.1.16 的对齐点（query.reset 空 target）在 0.1.42 仍有效。

## 设计器源码逆向 → 完整链路文档（docs/designer-full-chain.md）

- 源码包已解压 /tmp/ydf-ams-src（304MB）；pvdf-fe sourcemap 含完整原始源码，已还原 /tmp/ydf-src-extract/。
- 关键机制：组件注册三级表（registerWidgets 缓存 → widgetPath 内置90+业务13 → window.ydfui 扩展）；扩展脚本 window.YDFLoader(viewModal)→{ui[]}→window.ydfui，渲染与内置同构、无专属 DOM 标记。
- DOM 规则：叶子 fieldid=item.fieldid||divCode；表单字段=父divCode_dataField；LayoutItem 壳 id/class="wx-<key>" + fieldid="<divCode>_drag" + name=label；formItem class wx-item-<name>；表格列=表divCode_dataIndex；tableKey=guid() 不稳定禁用；弹窗 _modal/_modal_ok/_modal_cancel；无自定义 DOM 事件，Switch/Select/日期全是 click，表格单元格双击进编辑；值落 window.wxlcd.DM。
